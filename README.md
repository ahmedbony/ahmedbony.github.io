# S B Ahmed Bony - Curriculum Vitae

This repository hosts the CV using GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository named `ahmedbony.github.io`.
2. Upload these files to the root of the repository:
   - `index.html`
   - `.nojekyll`
   - `S_B_Ahmed_Bony_Academic_CV.pdf`
   - `S_B_Ahmed_Bony_Academic_CV.docx`
3. Commit the files to the `main` branch.
4. In the repository, open **Settings > Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. The site will be available at `https://ahmedbony.github.io/` after GitHub finishes publishing it.

The PDF is displayed directly by `index.html`; the CV content itself is not rewritten or edited.
